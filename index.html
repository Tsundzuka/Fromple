The workflow

Four steps. Full visibility.

Upload a file, set the rules, share a link, and watch who actually engages with it.

01 Upload

Drop the file.

Drag a PDF into the dashboard. It goes into a private bucket, never a public URL. Fromple never exposes the raw file to the browser — only a protected canvas render.

Upload a document
02 Restrict

Set the rules per link.

Require a name and email. Add a password, an expiry date, or lock it to one company's domain. Every link can carry a different policy — decided at share time.

Configure access
03 Share

Send one link.

Paste the URL anywhere — email, Slack, WhatsApp. No attachments, no downloads, no forwards. If it changes hands, you see it in the viewer log with IP and timestamp.

See the link manager
04 Track

Watch what happens.

Per-page reading time, drop-off points, unique viewers, and a live feed of activity as it happens. Revoke the link mid-session and the viewer locks instantly.
